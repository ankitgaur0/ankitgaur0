### What I Do
- Build **AI agents** and their environments, with guardrails to protect sensitive data
- Design **context engineering pipelines** so agents get the right context and produce the right output
- Research the best AI solution for each problem, balancing **quality, latency, and model cost** (open-source vs. third-party APIs)
- **Fine-tune** open-source models and **evaluate** them against the base model, so every improvement is backed by metrics
- Deploy and run models in production

### Agents and Orchestration
- **Orchestration patterns**: Supervisor, Swarm, Parallel, and Sequential, chosen per use case
- **Memory and context**: agent skills for passing and reusing context, plus state memory and long-term memory
- **MCP**: built MCP servers and integrated them with agents, APIs, and external tools

### RAG
- **Sequential RAG** and **Agentic RAG**
- Optimized retrieval with **namespacing**, **hybrid search**, **metadata filtering and sorting**, and **reranking**
- Retrieval with **OpenSearch** and **Elasticsearch** techniques, with attention to how data is chunked, indexed, and stored

### Evaluation
- **RAG evaluation**: retrieval quality (Recall@k, MRR, nDCG, context precision) and answer quality (faithfulness, answer relevancy)
- **Agent evaluation**: tool selection accuracy, task completion, and routing correctness
- **LLM-as-judge** checked against human-labeled samples
- **Golden question sets** and held-out data to compare models before and after changes

### ML, Deep Learning and NLP
- Traditional ML algorithms and different neural network architectures
- Strong NLP foundations, matching techniques to the use case
- **Fine-tuning** open-source models based on the use case, plus optimization techniques for speed and cost
- Comparing the fine-tuned model against the base model on a held-out set

### Voice and Document AI
- **Voice AI**: cascading **STT, LLM, TTS** pipelines
- **OCR and data extraction** using VLLMs, Azure Machine Learning models, and Tesseract

### Software Engineering
- **REST APIs**, **webhooks**, **WebRTC**, and CRUD operations designed around the use case
- **Databases**: vector DBs, MongoDB (with **ODM**), and time-series (**InfluxDB**)

### Currently Working On
- Fine-tuning open-source models and evaluating them after training
- Building evaluation harnesses for RAG pipelines and LLM applications
- Improving retrieval and search quality in agentic systems
